# -Este proyecto es una página web básica desarrollada como parte de un curso de Front-End-

La página está estructurada con HTML semántico y utiliza las etiquetas `<header>`,
`<main>`, y `<footer>` para organizar el contenido. Este sitio es el proyecto final para el curso de Front-End JS de Talento Tech. Mi proyecto se llama Your English Hub🌐
Professional English Training for the Modern Workplace
Está basado en mi propuesta educativa diseñada para ayudar a profesionales a dominar la comunicación en inglés en entornos laborales modernos y para la vida en general.

Estructura del sitio
Home: Introducción a la propuesta educativa.

Paths: Diferentes caminos de aprendizaje (Business, IT, etc.).

Method: Detalle de la metodología de enseñanza.

About Me: Información sobre mi perfil como Online English Teacher.

Pricing & Contact: Información comercial y canales de comunicación.

Cart: El carrito de compras de cursos.**
